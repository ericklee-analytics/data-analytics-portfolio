Customer Churn Risk Analysis

Business Problem

Customer churn represents a major revenue risk for subscription-based businesses. This project analyzes customer behavior and billing patterns to identify high-risk customers.

Tools Used

• Google Sheets
• SQL
• Tableau
• Data segmentation techniques

Key Analysis Steps

Data cleaning and preparation

Feature engineering (tenure groups, risk scores)

Churn trend analysis

Dashboard visualization

Key Insights

• Month-to-month contracts show the highest churn rate
• New customers (<12 months tenure) churn more frequently
• High monthly charges correlate with churn risk
